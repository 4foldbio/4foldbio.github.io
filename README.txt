4fold Bioscience website
========================

Static site: upload the contents of this folder to your web host
(or to the same place as the current site; the CNAME file keeps the 4fold.bio domain on GitHub Pages).

  index.html                the whole page
  images/                   photos, instrument, favicons, social share image (og-image.png)
  assets/fonts/             Inter typeface, self-hosted (no Google Fonts or other third-party requests)

No cookies, analytics or tracking are included.
